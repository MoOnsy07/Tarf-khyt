# LAST SEEN — Godot prototype

نموذج مستقل لأول ~10 دقائق من قضية **آخر مُشاهد** لاختبار هل نقل محرك اللعب من HTML/JS إلى Godot يستحق.

## الموجود
- ملف 45: فتح / تتبع / حذف
- تسجيل اسم اللاعب
- افتتاح آدم + LAST SEEN
- حركة كاميرا بطيئة + Fade + Glitch
- مؤثرات صوتية مولدة داخل المحرك
- اختفاء آدم
- تفتيش الشقة بـ Hotspots حقيقية
- 4 أدلة، واللاعب يقدر يفحص 3 فقط
- Timer حقيقي 150 ثانية
- أول إفادة للشرطة
- Save/Resume داخل `user://`
- Web export preset

## التشغيل
1. افتح مجلد `godot/last-seen-prototype` في Godot 4.x.
2. Run Project.
3. للويب: Project > Export > Web.

المشروع يستخدم Compatibility renderer ليكون مناسبًا للويب.

هذا Vertical Slice فقط. لو إحساس اللعب أفضل من نسخة Story Mode الحالية، نكمل من **المراقب 00** على نفس البنية بدل نقل القضية كلها مرة واحدة.
